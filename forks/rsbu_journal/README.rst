Журнал бухгалтерских проводок по российским стандартам (РСБУ) — ядро
РСБУ-слоя. Ведёт учёт методом двойной записи по плану счетов 94н и
обеспечивает расчёт оборотов и сальдо. Нативная бухгалтерия Odoo не
затрагивается.

Возможности
===========

* Проводки по методу двойной записи (дебет / кредит)
* Аналитика (субконто): контрагент, товар, пользователь, сотрудник
* Контроль баланса проводки при проведении
* Контроль обязательности заполнения субконто
* Обороты и сальдо по счетам рассчитываются из проведённых проводок
* Учёт в рублях, поддержка нескольких компаний в одной базе

Использование
=============

#. Перейдите в *РСБУ > Журнал операций*.
#. Создайте проводку: укажите дату, счета по дебету и кредиту и суммы.
#. Заполните субконто, если они обязательны для выбранных счетов.
#. Проведите проводку — она попадёт в обороты и сальдо плана счетов.

Как правило, проводки формируются автоматически при проведении
документов (см. модуль коннектора). Ручной ввод используется для
корректировок и операций без документа-источника.
