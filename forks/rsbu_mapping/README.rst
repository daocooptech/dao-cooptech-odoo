Задаёт правила, по которым документы Odoo превращаются в проводки РСБУ:
какие счета дебетуются и кредитуются для каждой хозяйственной операции.
Модуль наполняет коннектор документов логикой формирования проводок.

Возможности
===========

* Шаблоны операций с указанием ролей счетов (дебет / кредит)
* Матрица связности — подбор нужного шаблона по типу документа и
  параметрам операции
* Поддержка полного коммерческого цикла:

  * получение аванса (в т. ч. НДС с аванса)
  * возврат аванса
  * реализация / отгрузка (выручка, НДС, зачёт ранее полученного аванса)
  * постоплата

Настройка
=========

#. Перейдите в *РСБУ > Настройка > Шаблоны операций*.
#. Создайте шаблон и укажите роли счетов (какие дебетуются, какие
   кредитуются).
#. Настройте правила матрицы связности, чтобы система подбирала шаблон
   автоматически по типу документа.

Готовый набор шаблонов для типовых сценариев можно установить из модуля
демо-шаблонов операций.

Использование
=============

После настройки шаблонов проводки РСБУ формируются автоматически при
проведении документов — отдельных действий не требуется.
