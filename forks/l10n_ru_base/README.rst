Настройка
=========

#. Перейдите в *Настройки* и откройте в боковом меню раздел
   «Российская локализация».
#. Включите нужные блоки, чтобы подключить дополнительные возможности
   локализации.

Состав локализации
==================

Модуль объединяет пакет модулей российской локализации:

* Акт сверки
* Доверенность
* Договоры
* Документы (первичные печатные формы)
* УПД в формате XML
* Авансовые платежи
