Автоматически формирует проводки РСБУ при проведении документов Odoo —
счетов и платежей. Пользователь работает как обычно, а параллельный
слой РСБУ создаёт соответствующую запись в журнале хозяйственных
операций.

Возможности
===========

* Проводка РСБУ создаётся в момент подтверждения документа
* При отмене или возврате документа в черновик проводка удаляется
* Журнал РСБУ всегда соответствует текущему состоянию документов
* Переход из документа к связанной проводке РСБУ и обратно

Использование
=============

Модуль работает автоматически и не требует ручных действий:

#. Проведите счёт или зарегистрируйте оплату обычным образом.
#. Проводка РСБУ будет создана автоматически по правилам из модуля
   шаблонов операций.
#. Чтобы увидеть проводку, откройте документ и перейдите по ссылке к
   связанной записи РСБУ.

Правила формирования проводок (какие счета дебетуются и кредитуются)
настраиваются в модуле шаблонов типовых операций. Коннектор отвечает
только за своевременное создание и удаление записей.
