Учёт НДС для плательщиков УСН, которые обязаны исчислять налог. НДС
учитывается на основании счетов-фактур и проводок журнала РСБУ.

.. contents::
   :local:

Возможности
===========

* Настройка ставки НДС: освобождён, 5% или 7%
* Счета-фактуры: авансовые, отгрузочные, корректировочные
* Книга продаж и книга покупок формируются из проводок НДС
* Свод итогов по НДС и расчёт суммы декларации за период
* Пересчёт данных за выбранный период

Настройка
=========

#. Перейдите в *Настройки* и укажите применяемую ставку НДС.

Использование
=============

#. Оформляйте счета-фактуры к операциям реализации и поступления.
#. Книга продаж и книга покупок, а также итоговые суммы для декларации
   рассчитываются автоматически из проводок НДС.
#. Откройте *РСБУ > НДС*, чтобы просмотреть книги и свод по НДС.
#. При необходимости пересчитайте данные за нужный период через
   соответствующий мастер.
