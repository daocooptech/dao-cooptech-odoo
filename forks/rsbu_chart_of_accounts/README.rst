Независимый план счетов бухгалтерского учёта по российским стандартам
(РСБУ), построенный по Приказу Минфина России № 94н. Это базовый модуль
РСБУ-слоя, на котором строятся журнал проводок, КУДиР и учёт НДС.
Нативная бухгалтерия Odoo при этом не затрагивается.

Возможности
===========

* Иерархический план счетов произвольной глубины (счета и субсчета)
* Признак счёта: активный, пассивный, активно-пассивный, забалансовый
* Флаги обязательных субконто (контрагент, товар, пользователь, сотрудник)
* Расчёт оборотов и сальдо по дереву субсчетов
* Типовой план счетов 94н как готовые данные
* Ведение отдельного плана счетов для каждой компании

Настройка
=========

#. Установите модуль — типовой план счетов 94н загрузится автоматически.
#. Откройте *РСБУ > Настройка > План счетов*, чтобы просмотреть или
   скорректировать счета.
#. При необходимости загрузите типовой план счетов повторно через
   соответствующий мастер.

Использование
=============

#. Перейдите в *РСБУ > План счетов*.
#. Просматривайте иерархию счетов, обороты и сальдо.
#. Для каждого счёта настройте обязательность субконто, чтобы система
   контролировала аналитику при проведении проводок.
